## api/queue實作理解
| 程式碼片段 | 你的理解 | 專業術語 (補充) |
|---|---|---|
| type Client interface | 定義 client 可以使用的功能 | 抽象介面 (Abstraction) |
| type RedisClient struct | 定義定位 redis queue 需要的資訊 | 具體實作 (Concrete Implementation) |
| func NewRedisClient | 建立 redis 連線 | 實體化工廠 (Constructor) |
| type Publisher struct | 符合 Client 介面(在此project是實際存放 redis 回傳的 client) | 依賴持有者 (Dependency Holder) |
| func NewPublisher | 在 main.go 使用，傳入 client | 依賴注入 (Dependency Injection) |
| func Publish | api/create.go 實際使用的功能 | 業務邏輯入口 (Entry Point) |
